# 尊嘟假嘟 · AI 家庭谣言核查

> 爸妈群里转的那些「震惊！」「转给家人」，到底**尊嘟，还是假嘟？**
>
> 一个帮年轻人「替爸妈核查谣言」的 AI Agent。核查只是手段，真正解决的是——**你和爸妈之间，因为谣言产生的矛盾。**

赛道：AI Agent · 信息真相猎人

---

## 这是什么

家庭群里的谣言，你讲道理没用、查到真相也没用，因为你不知道「怎么跟爸妈说」。

尊嘟假嘟做四件事：

1. **核查** —— 调查记者式四步链（溯源 → 交叉验证 → 逻辑推演 → 证据链），知识库 + 联网权威源双路核查
2. **看穿** —— 生成「四宫格漫画」，用爸妈能看懂、会心一笑的大白话拆穿套路（不上课、只让看穿）
3. **说给谁听** —— 同一个真相，按对象（爱面子 / 易焦虑 / 固执）重写成不同语气的话
4. **转发** —— 一键生成适老化卡片图片，直接发回家庭群

## 5 分钟跑起来（无需任何 API key）

```bash
cd fact_hunter
pip install -r requirements.txt
python app.py
# 浏览器打开 http://127.0.0.1:5000
```

不配 key 也能跑：内置种子数据走「知识库命中」路径（命中即秒出、且离线），可以直接体验四宫格、说给谁听、保存卡片等核心功能。

## 接入大模型（完整能力）

核查推理、写四宫格、写「说给谁听」由大模型完成；联网搜权威来源由博查（Bocha）完成。配置环境变量后启动即可，代码无需改动：

```bash
# 大模型（推荐 360 智脑：同时拿"国产模型"与"360 生态联动"两项分）
export LLM_API_KEY=你的360key
export LLM_BASE_URL=https://api.360.cn/v1
export LLM_MODEL=360gpt-pro
export LLM_AUTH_PREFIX=""        # 360 智脑鉴权前缀留空

# 联网核查（博查 Web Search）
export BOCHA_API_KEY=你的博查key

python app.py
```

> 大脑 = 360 智脑（推理 / 判断 / 写内容）；上网的手 = 博查（去权威网站搜资料）。

可选：装上 `sentence-transformers faiss-cpu` 可启用向量语义检索（不装则自动降级为关键词匹配，不影响演示）。

## 项目结构

```
fact_hunter/
├── app.py              # Flask 主程序：网页、核查路由、卡片渲染、说给谁听
├── verifier.py         # 核查引擎：四步链、知识库/联网双路、四宫格生成、可信度分层
├── knowledge_base.py   # 知识库：FAISS 向量检索（自动降级关键词）、记忆热更新
├── llm.py              # 大模型调用封装
├── config.py           # 全局配置（模型、阈值、路径，全部可用环境变量覆盖）
├── index.html          # 前端：四步显形动画、长辈卡片、四宫格、说给谁听、保存图片
├── card_template.html  # 转发卡片模板
├── seed_data.json      # 种子谣言数据（含头孢/维C/隔夜水等核查案例）
├── requirements.txt    # 依赖
└── README.md
```

## 技术亮点

- **可信度分层**：知识库权威源 → 联网权威域名 → 全网兜底（标注「非权威」）→ 模型常识（标注「待官方」），诚实呈现准确性，不假装权威
- **记忆机制**：库外谣言核查后自动写回知识库并热更新索引，同一条第二次秒级复用，越用越快
- **联网只搜权威域名**：博查优先在 piyao.org.cn、卫健委、央广网等权威白名单内搜索，搜不到再全网兜底并标注
- **高危强提示**：用药等高危类谣言强制附安全提示
- **共享知识库架构**：FAISS 为共享层，架构支持横向扩展出多个垂直 Agent
